الأمرالوظيفة

2. Event-Driven & Inversion of Control (IoC)

In an event-driven program, the flow is determined by events.

  • Console: Your Code calls the Library.
  • GUI (IoC): The Framework calls your Code.
  • مثال: button.Click += OnClick; هنا نسجل الدالة فقط ولا نستدعيها.

3. أهم تعاريف الأحداث

  • Event: Something that happened.
  • Event Source / Sender: The object that raised/caused the event.
  • Event Data: Details about the event (e).
  • Event Handler: Code that runs in response.
  • Subscription: Linking a handler to an event.
  • Event Loop: Waits for events and dispatches them.

5. أنواع الأحداث (Categories)

  • User Input: Click, KeyDown, MouseMove
  • Text Events: TextChanged
  • Selection: SelectionChanged
  • Window: Loaded, Closing, Closed
  • Time: DispatcherTimer Tick

6. قواعد كتابة Event Handler

  • Keep handlers short (اجعلها قصيرة).
  • Validate input first (تحقق من المدخلات أولاً).
  • One handler, one job (مهمة واحدة لكل معالج).
  • Reuse handlers instead of copying them.

1 & 2. أول برنامج Button Click (XAML + C#)

XAML (XML) 
<StackPanel Margin="15">
    <Button Content="Click me"
            Click="Hello_Click" />

int clicks = 0;

private void Hello_Click(object sender, RoutedEventArgs e)
{
    clicks++;
    lblOut.Text = $"Clicked {clicks} times";
}
// الناتج: Clicked 1 times ثم 2 ثم 3...
خطأ امتحاني مهم: يمكنك ربط الحدث إما في XAML (Click="BtnSave_Click") أو في C# (btnSave.Click += BtnSave_Click;). لا تستخدم الطريقتين معاً لنفس الحدث؛ لأن الدالة ستعمل مرتين عند الضغط!

Delegate: A type-safe reference to a method. (متغير يخزن مرجعاً لدالة).

5. برنامج ComboBox + Button + Delegate (مهم جداً)

XAML 
<StackPanel Margin="15">
    <TextBox x:Name="txtName" Width="200" />
    <ComboBox x:Name="cmbLang"
              SelectedIndex="0"
              SelectionChanged="Lang_Changed">
        <ComboBoxItem Content="English" />
        <ComboBoxItem Content="Spanish" />
    </ComboBox>
    <Button Content="Greet" Click="Greet_Click" />
    <TextBlock x:Name="lblOut" />
</StackPanel>
C# Code-Behind 
Func<string, string> greeter = English;

static string English(string n) => $"Hello, {n}!";
static string Spanish(string n) => $"Hola, {n}!";

private void Lang_Changed(object sender, SelectionChangedEventArgs e)
{
    greeter = cmbLang.SelectedIndex == 1 ? Spanish : English;
}

private void Greet_Click(object sender, RoutedEventArgs e)
{
    lblOut.Text = greeter(txtName.Text);
}

Week 7 – Publisher/Subscriber & Routed Events

Publisher (الناشر)

  • • Declares the event (يُصرّح بالحدث).
  • • Raises the event (يُطلق الحدث وحده).
  • • لا يعرف من يستمع إليه.

Subscribers (المشتركون)

  • • Add themselves using +=
  • • Remove themselves using -=
  • • الكود الخارجي يستخدم += و -= فقط.

3 & 4. برنامج Counter (Publisher & Subscribers)

Counter Class (Publisher) 
public class Counter
{
    public int Value { get; private set; }
    public event EventHandler<int>? ValueChanged;

    public void Increment()
    {
        Value++;
        ValueChanged?.Invoke(this, Value);
    }
}
MainWindow (Subscribers) 
Counter counter = new Counter();

public MainWindow() {
    InitializeComponent();
    counter.ValueChanged += ShowCount;
    counter.ValueChanged += MoveBar;
}
void ShowCount(object s, int v) => lblCount.Text = $"Count: {v}";
void MoveBar(object s, int v) => bar.Value = v;
void Add_Click(object s, RoutedEventArgs e) => counter.Increment();

7. Routed Events (Bubbling, Tunneling, Direct)

Routed Events are events that travel through the element tree.

1. Bubbling (يصعد)
Window (3)
↑
StackPanel (2)
↑
Button Source (1)

Source → Parent → Window
مثال: Click

2. Tunneling (ينزل)
Window (1)
↓
StackPanel (2)
↓
Button Source (3)

Window → Source
يبدأ بـ Preview مثل PreviewKeyDown

3. Direct (مباشر)
Window
×
StackPanel
×
Source Only (1)

يحدث على العنصر نفسه فقط
مثال: Loaded

sender vs e.Source:
• sender: العنصر الذي تم ربط الـ Handler به (مثلاً StackPanel).
• e.Source: العنصر الأصلي الذي أطلق الحدث فعلياً (مثلاً Button).
• e.Handled = true; توقف استمرار توجيه الحدث.

Week 8 – Layout and XML (الصفحات 1–17 فقط)

مقيد بالصفحات 1–17
DockPanel يثبت العناصر في Top, Bottom, Left, Right. آخر عنصر يملأ المساحة المتبقية افتراضياً (LastChildFill="True").
Grid ينظم العناصر بصفوف (Rows) وأعمدة (Columns). يدعم Auto (حجم المحتوى) و * (المساحة المتبقية النسبية).

GroupBox يجمع العناصر داخل إطار بعنوان (Header). يحتوي Child واحداً مباشراً (نضع داخله Grid).
Margin vs Padding:

• Margin: Space Outside (المسافة خارج العنصر). ترتيب 4 أرقام: Left, Top, Right, Bottom.

• Padding: Space Inside (المسافة داخل العنصر).

<Button Content="Save" Margin="10" Padding="15" />
